# Orbit — 개인 AI 비서

Vercel 배포용 Next.js 앱입니다. 한국어 반응형 채팅, 스트리밍, 비밀번호 로그인, 대화 저장/삭제, 비서 지침, 기억/자료 수정, 답변 개선 사례, JSON 내보내기를 제공합니다. 지침과 자료를 매 요청에 반영하며 모델 가중치를 학습시키지는 않습니다.

## 로컬 실행

1. `npm install`
2. `.env.example`을 `.env.local`로 복사합니다.
3. `OPENAI_API_KEY`, `ASSISTANT_PASSWORD`(최소 16자 권장)를 입력합니다. `OPENAI_MODEL`은 사용 가능한 모델 ID로 변경할 수 있습니다.
4. `npm run dev` 후 http://localhost:3000 에 접속합니다.

API 키는 서버 환경 변수에만 보관합니다. ChatGPT 구독과 API 사용료는 별개입니다. 앱은 API 키를 브라우저로 보내지 않습니다.

## Vercel 배포

1. 이 프로젝트를 본인 GitHub 저장소에 올립니다.
2. Vercel → Add New → Project → 해당 저장소를 가져옵니다. Framework는 Next.js입니다.
3. Environment Variables에 위 변수들을 입력합니다.
4. Deploy 후 생성된 주소에서 비밀번호로 로그인합니다.
5. Vercel Firewall에서 `/api/session`에 로그인 시도 제한, `/api/chat`에 요청 수 제한을 설정합니다. OpenAI 프로젝트 사용량 알림/예산도 설정하세요. 앱 자체에는 월 예산 차단 기능이 없습니다.

## 기기 간 저장 (권장)

Supabase 프로젝트를 만들고 SQL Editor에서 `supabase.sql`을 실행하세요. 서버 환경 변수 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 설정하고 재배포합니다. service role 키는 절대로 NEXT_PUBLIC_ 변수로 만들지 마세요. RLS와 공개 역할 권한 차단을 포함합니다.

미설정 상태에서는 브라우저 localStorage에 저장합니다. 브라우저 데이터 삭제 시 유실될 수 있으니 설정에서 내보내기하세요. 공용 기기에서는 사용하지 마세요. 로그아웃은 세션을 종료하지만 해당 브라우저의 로컬 백업은 남습니다. 클라우드 연결 시 처음 로그인할 때 불러오고 변경 후 자동 저장합니다. 동시 편집은 마지막 저장 우선이며 실시간 병합이 아닙니다. 이 앱은 단일 소유자 전용입니다.

## 맞춤 설정

- 비서 설정: 역할, 규칙, 답변 형식을 변경합니다.
- 기억과 자료: 확정 정보와 참고 자료를 추가/편집/삭제합니다.
- 답변 개선: 질문/기존 답변/개선 지침을 사례로 저장합니다.
- 다음 요청부터 최근 메시지 30개, 지침, 기억, 개선 사례를 모델에 전송합니다. 각 설정 묶음은 20,000자 이내입니다.
- 파일 업로드, 자동 장기 기억, 외부 업무 실행, 일정/메일 연동, 파인튜닝은 아직 포함하지 않습니다.

## 모델 선택과 HUD

채팅 입력창 왼쪽에서 모델을 선택합니다. 로그인 후 서버가 OpenAI `/v1/models`에서 일반 텍스트 모델 별칭을 검색합니다. API 키는 서버에서만 사용합니다. 계정에 모델이 표시되더라도 결제/프로젝트 권한 등에 따라 실제 호출이 제한될 수 있습니다. 목록 검색 실패 시 서버 기본 모델만 제공합니다.

`OPENAI_MODEL`은 기본 모델입니다. 필요하면 `OPENAI_MODELS`에 허용할 모델 ID를 쉼표로 입력할 수 있습니다. 이 값을 설정하면 자동 검색 대신 해당 목록만 사용합니다(기본 모델 포함). Astra/Sol/Luna/Terra 계열은 Responses API, 기존 일반 모델은 Chat Completions API로 연결합니다. 명시하는 모델은 해당 API의 텍스트 스트리밍을 지원해야 합니다. 클라이언트의 임의 모델 요청은 서버 허용 목록으로 검사합니다. 선택은 다른 설정과 함께 저장되고, 답변 옆에 실제 요청 모델을 표시합니다.

상단 `HUD ON/OFF`로 스캔·레이더·신호 애니메이션을 끌 수 있습니다. 기기의 ‘동작 줄이기’ 설정도 지원합니다. HUD의 기억/대화 수는 실제 저장 데이터에서 계산합니다.

## 사용량 모니터

왼쪽 ‘사용량’ 메뉴 또는 상단 토큰 카운터에서 오늘/이번 달/전체 토큰, 입력/출력, 요청 시도 수, 모델별 합계, 최근 요청을 확인합니다. 날짜 경계는 Asia/Seoul(KST)입니다. Chat Completions의 `stream_options.include_usage` 또는 Responses API의 완료 이벤트로 받은 실제 usage 값을 저장합니다. 캐시/추론 토큰은 각각 입력/출력의 부분집합으로 중복 합산하지 않습니다.

기능 적용 후 이 앱에서 기록한 요청만 집계하며 기존 대화는 소급 집계하지 않습니다. 대화를 삭제해도 별도 사용 기록은 유지됩니다. 기본 저장은 현재 브라우저이고 Supabase 연결 시 다른 앱 설정과 함께 동기화합니다. 데이터 내보내기에 사용 기록도 포함합니다. 클라이언트 기록이므로 서버 결제 원장이나 예산 차단 수단으로 사용하지 마세요.

중단/연결 오류/페이지 종료 시 usage 청크가 도착하지 않을 수 있습니다. 확인되지 않은 요청은 ‘미확인’으로 표시하며 0원/미과금이라는 의미가 아닙니다. 새로고침으로 남은 pending 기록은 ‘진행 중 / 미완료’로 표시합니다. 실제 청구 금액, 잔액, 다른 앱 사용량을 포함한 계정 전체 사용량은 https://platform.openai.com/usage 에서 확인하세요. 금액은 모델별 최신 요율과 다른 과금 항목을 검증하지 않은 추정치로 표시하지 않습니다.

## Astra / Sol / Luna

모델 자동 검색은 `gpt-6-astra`, `gpt-6.1-sol`, `gpt-6-sol`, `gpt-6-luna` 및 이전 세대의 Sol/Luna/Terra 별칭을 포함합니다. 이 계열은 Responses API를 사용하며, 추론 수준은 low, 출력+추론 한도는 8,000토큰입니다. 기존 모델의 2,500토큰 한도와 다릅니다. 실제 접근 가능 여부는 API 프로젝트 권한과 결제 상태에 따릅니다.

`OPENAI_MODELS`를 설정한 경우 자동 검색이 꺼지므로 최신 모델을 목록에 직접 추가하거나 변수를 삭제하세요. 예: `gpt-6.1-sol,gpt-6-astra,gpt-6-luna`. 기본 모델은 `OPENAI_MODEL=gpt-6.1-sol`로 지정할 수 있습니다. 모델별 과금은 다르며 자동 전환은 하지 않습니다.
